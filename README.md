# 🌙 Glowing Glassmorphism Mode Toggle

A sleek, modern, and highly interactive UI toggle switch built with **HTML5**, **CSS3 (Custom Properties & Glassmorphism)**, and **Vanilla JavaScript**. 

It features dynamic theme transitions (Dark "Sleep" Mode ↔ Light "Work" Mode), realistic glass reflection effects, smooth CSS spring animations, and subtle audio-visual tactile feedback[cite: 1].

---

## ✨ Features

- **Liquid Glassmorphism Effect:** Advanced backdrop-blur, semi-transparent borders, and multi-layered radial gradients for realistic visual depth[cite: 1].
- **Dynamic Background Transition:** Smoothly transitions the page background between deep midnight blue (Sleep mode) and soft neutral grey (Work mode)[cite: 1].
- **Custom Glass Thumb Reflection:** Rotating frosted glass knob with specular lighting overlays[cite: 1].
- **Zero Dependencies:** Pure HTML, CSS, and Vanilla JS — no external frameworks required[cite: 1].
- **Fully Responsive & Accessible:** Scalable design with native keyboard navigation support (`Space` / `Enter`)[cite: 1].
